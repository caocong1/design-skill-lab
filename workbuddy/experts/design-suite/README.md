# Design Suite（黛米 Demi）— WorkBuddy 专家包

产品设计负责人专家：内嵌 design-studio、critique-design、implement-design 三个技能，
覆盖「设计 → 评审 → 实现」完整闭环。

- 做一个新设计 / 改版 / 单个页面组件：design-studio 全流程（设计解读 → 方向 → 设计系统 → 渲染验证 → 交付）
- 评审现有设计或构建、无障碍走查、还原度验收：critique-design
- 按设计稿或交接包在项目里实现：implement-design

设计产物写入 `.design/`；契约介质为 HTML/CSS/SVG，一切以渲染结果为准。
