# NOTES · 拾光到家「服务」页

- 三个 HTML 共用 `out/common.css`（相对路径，file:// 直接打开即可）；HTML 由工作目录下的 `gen.mjs` 生成，`render.mjs` 输出 PNG。
- 所有图形（状态栏图标、胶囊占位、服务缩略图、标签栏图标、空状态插画）都是手绘内联 SVG，没有外部图片或字体；字体用系统 PingFang SC。
- 胶囊按钮按 brief 画在 left 281 / top 50 / 87×32；自定义导航栏只在左侧放位置切换（右边界 243px），不放页面标题，避开胶囊。
- 导航栏下依次为搜索框、类目横滑、排序/筛选条；列表内容区从 216px 到标签栏顶部 729px，标签栏 49px + 安全区 34px。
- 类目超出一屏：横向滚动，只完整显示前 4 个，右侧「类目宫格」按钮打开全部类目，避免出现被截半的文字。
- 排序条宽度放不下 4 个排序项 + 筛选：直接显示「综合排序▾ / 距离最近 / 价格最低」，「评分最高」收在「综合排序」下拉里（假设价格对这群用户更关键；评分已在每张卡片上展示）。
- 「自营」小标只加在「拾光自营保洁队」上，依据 brief 中“平台自营团队”的描述，不是新增功能。
- 距离用导航箭头图标 + km，放在评分行右侧；“今天”可约的时间用品牌绿突出，其他日期用深色文字。
- 列表卡片整张可点，没有单独“预约”按钮（节省空间，保证第一屏完整看到 3 个服务的价格、评分、最近可约）。
- 筛选面板用从排序条下拉的面板 + 遮罩，而不是底部半屏弹层：小程序页面内的遮罩盖不住原生标签栏，下拉面板更符合平台实际。标签栏保持可见、不变暗。
- 筛选面板背后的列表是「家电清洗」类目下 brief 已有的服务（空调、油烟机、洗衣机），被遮罩覆盖。
- 「服务人员」默认选中「不限」（单选组）；「服务保障」为多选；其余组为单选。价格组未选。
- 「查看结果」按钮显示 0 个并附一行“当前条件下暂无匹配服务”，仍可点击进入空状态页。
- 空状态：顶部保留已生效的筛选条件（可单独移除），说明原因，并列出 brief 给出的 3 个放宽建议（3 km 内 4 个、明天 6 个、去掉可开发票 1 个），每行可直接点；底部「修改筛选」「清除筛选」。
- 「清除筛选」只清除上门时间/距离/保障 3 个筛选，保留「家电清洗」类目。
- 颜色对比度已按 WCAG 公式检查：品牌绿 #117A55 在白底 5.33:1、在浅绿底 4.77:1；价格橙红 #C43D0A 5.23:1；次要文字 #5C5F66 6.4:1；标签栏未选中 #62666D 5.77:1；搜索占位 #6B6F76 在 #F2F3F5 上 4.55:1。
- 正文最小 13px，标签栏文字 11px（接近原生标签栏字号），关键信息（价格、时间、标题）15–20px，照顾调大字号的用户。
