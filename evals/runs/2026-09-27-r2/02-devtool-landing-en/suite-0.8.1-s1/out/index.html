Your app’s data lives on the device first.

Driftless is an open-source SQL database that runs inside your app. Reads and writes are local, so they’re instant and work offline. Driftless keeps every copy in sync.

Two people edit the same row offline. Nobody writes conflict code.

Driftless tracks changes per column with hybrid logical clocks, so concurrent edits to different fields both survive.

  1. Your app writes to its local database

    No request, no spinner. Pending changes survive restarts, so the app keeps working offline.

  2. Driftless records the change and merges

    Concurrent edits merge per column. Register custom merge functions for counters, lists and rich text.

  3. The sync server relays it

    Every other device that holds matching rows receives the change in the background.

Sync runs through the Driftless Sync Server: open source, one binary, backed by Postgres or SQLite. Or use Driftless Cloud, the managed version.

What you get in the box

Partial sync with shapes

Each user syncs only the rows a filter selects. Generally available in 1.4.

WHERE team_id = ?

Reactive queries

db.watch re-runs a query whenever matching rows change, whether the change was local or arrived from sync.

Your auth, checked on the server

Bring your own JWT. Row-level rules are checked by the sync server.

Offline that survives restarts

The app keeps working with no connection, and pending changes are kept across restarts until they sync.

You never need Driftless Cloud: the sync server is a single open-source binary you can run anywhere.

Questions developers ask first

Is it SQLite?
The storage engine is a fork of SQLite 3.46 with sync metadata; most SQLite SQL runs unchanged. Extensions that change the file format are not supported.
Do I need Driftless Cloud?
No. The sync server is a single open-source binary you can run anywhere; Cloud is the managed version.
How big can a local database get?
Browser storage limits apply (usually a share of free disk). On native platforms the tested limit is 50 GB.
What happens when two people edit the same row offline?
Each column merges by hybrid logical clock; register custom merge functions for counters, lists and rich text.
