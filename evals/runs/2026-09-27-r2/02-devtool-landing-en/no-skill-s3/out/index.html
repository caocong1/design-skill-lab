How it works

The database is in your app. The network is optional.

Instead of asking a server and caching the answer, every device holds a real SQL database. Driftless moves changes between the copies in the background.

  1. 1 Write

    Your app writes to its local database

    Plain SQL against an embedded, SQLite-compatible engine. No round trip, no loading state, no offline branch.

    This device
    app→INSERT INTO notes …
    notes.dbcommitted locally
  2. 2 Record & merge

    Driftless records the change and merges per column

    Every change is stamped with a hybrid logical clock. Concurrent edits to different columns both survive.

    colphonelaptop title“Q3 plan”“Plan” body“draft”“final” donetrue—
  3. 3 Relay

    The sync server relays it to every matching device

    Only devices that hold matching rows get the change. When one is offline, it catches up when it reconnects.

    sync server
    → browser → iOS app → desktop

What you get

One database, everywhere your app runs

Embedded SQL

SQLite-compatible dialect on a fork of SQLite 3.46. Most SQLite SQL runs unchanged.

Background sync

Through the open-source Sync Server (one binary, Postgres or SQLite) or Driftless Cloud.

Per-column merges

Hybrid logical clocks resolve conflicts automatically. Custom merges for counters, lists and rich text.

Reactive queries

db.watch re-runs a query whenever matching rows change, locally or from sync.

Partial sync with shapes

Each user syncs only the rows a filter selects, e.g. WHERE team_id = ?

Your auth, your rules

Bring your own JWT. Row-level rules are checked by the sync server.

Offline by default

The app keeps working offline, and pending changes survive restarts.

690 KB in the browser

Gzipped WebAssembly bundle, storing data in OPFS. 30% smaller in 1.4.

FAQ

The questions you should ask

Is it SQLite?

The storage engine is a fork of SQLite 3.46 with sync metadata; most SQLite SQL runs unchanged. Extensions that change the file format are not supported.

Do I need Driftless Cloud?

No. The sync server is a single open-source binary you can run anywhere; Cloud is the managed version.

How big can a local database get?

Browser storage limits apply (usually a share of free disk). On native platforms the tested limit is 50 GB.

What happens when two people edit the same row offline?

Each column merges by hybrid logical clock. Register custom merge functions for counters, lists and rich text.
