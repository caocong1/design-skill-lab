# Dogear: notes and assumptions

- Font is the system font (`-apple-system`, which is SF Pro in Chrome on macOS). Book quotes and cover lettering use Newsreader from Google Fonts (OFL licence), with Georgia as the fallback.
- All icons, covers and the empty-state illustration are hand-drawn inline SVG or CSS. There are no external images.
- iOS 26 look: a floating Liquid Glass tab bar (Today, Library, Stats) with Search as a separate glass button on the right; round glass toolbar buttons; large titles; inset grouped cards with large corner radii.
- The tab bar sits entirely above the bottom 34 pt (y 774–836), so nothing you can tap overlaps the home-indicator area. The top 62 pt contain only the status bar. The Dynamic Island is not drawn, just as it is absent from a real screenshot.
- Content scrolls under the tab bar. A soft scroll-edge fade (opaque by the bottom of the tab bar) stops cut-off text from showing faintly below it.
- Accent colour is terracotta #A8431B: 6.0:1 on white, 5.4:1 on #F2F2F7, about 5:1 on the selected-tab pill. Secondary text is #5E5E63 (≥5.8:1). The glass surfaces are 80% white, so dark labels on them stay above 7:1 whatever is behind.
- Today: "Start Session" uses the most recent book (Middlemarch). No book is named on the button because the brief doesn't say which book a session starts with.
- Today: "8 min to go" (20 − 12) and "This Week · 125 min" (the sum of the given daily minutes) are calculated from the brief's data, not invented.
- Today: the week chart is a single series, so it has no legend. The dashed line marks the 20-minute goal. Today's bar is hatched and labelled "Today" to show it is still in progress, so colour is not the only cue.
- Today: the Recent Highlight card comes after Currently Reading and sits just below the first screen (it is in the HTML).
- Today: the top-right "M" avatar is the account button (Maya). On the first-run screen it is a generic person icon, because the new user has no profile yet.
- Book detail is pushed inside the Library tab, so the tab bar stays visible with Library selected. The back button is an iOS 26 glass chevron.
- Book detail: Mark as Finished, Edit Goal and Remove from Library sit behind the "…" glass button (a pull-down menu, shown closed). Start Session is the prominent tinted button; Log Pages and Add Highlight are grey secondary buttons.
- Book detail: the cover subtitle "A Study of Provincial Life" is the novel's real subtitle. It is the only text added that is not in the brief.
- Book detail: "See All" under Sessions stands for the full list of 23 sessions; four are shown. The Highlights section (both quotes) is below the first screen.
- First run: Scan Barcode is the single prominent action. Search by Title and Import from CSV File are secondary list rows. The daily goal is preset to 20 minutes and changed with an iOS stepper.
- First run: the CSV row's subtitle "A list exported from another app" is explanatory copy I added.
- The date format follows the brief ("Sunday, 27 September", day before month).
- PNGs were rendered with Playwright and Chrome at 402 × 874, DPR 2 (`render.mjs`). The HTML is generated by `build.mjs` (neither script is part of the deliverable).
