# 假设与决定（每条一行）

- HTML 由 `../gen/*.mjs` 生成（`node gen/build.mjs && node gen/render.mjs`），交付的 HTML 是自包含静态文件，无外部依赖，字体使用系统 PingFang SC。
- 组织切换显示「恒川精密 · 苏州一厂」，但列表数据含二厂工单；按 brief 原样呈现，假设组织切换不对「全部」视图做厂区过滤。
- 列表把「设备」拆成两行（编号 / 名称），「SLA」拆成「类型 / 时长」两行，文字不变，只为在 1440 宽内放下全部 10 列且不截断。
- SLA 颜色规则：已超时 = 红色 + 警示图标 + 行首红色竖条；剩余不足 1 小时（响应剩 35分）= 橙色；按时 = 绿色对勾；超时后修复 = 橙色警示；计时暂停 = 灰色暂停图标。均带文字和图标，不只靠颜色。
- 「已挂起（等备件）」显示为「已挂起」状态标签 + 下方小字「等备件」。
- 状态标签每种都有独立图标（待派单虚线圈、已派单纸飞机、处理中半圆、已挂起暂停、待验收清单、已关闭对勾）；优先级标签始终带「P1 紧急」等文字。
- 选中第 2、3 行时，表头复选框显示半选状态，工具栏变为批量操作栏（已选 2 项 / 批量派单 / 批量修改优先级 / 导出所选 / 取消选择）。
- 「列设置」放在表格工具栏右侧；「新建工单」「导出全部」放在页头右侧。
- 分页：1,286 / 15 = 86 页，每页条数以下拉形式显示「15 条/页」。
- 空状态：三个筛选条件在筛选栏高亮并以可移除的标签列出，给出「清除全部筛选」和「新建工单」两个出口；不暗示其他厂区有数据（brief 未提供）。
- 加载中：快捷视图数量、表格行均为骨架屏，工具栏显示「正在加载工单…」，批量操作禁用；筛选项可用。
- 出错：假设快捷视图数量与列表来自同一接口，因此数量显示「—」；展示 HTTP 502、请求编号、时间，提供「重试」和「复制请求编号」；文案建议连续失败时联系系统管理员（未指定具体人员）。
- 详情页「更多」里的打印工单、复制链接、关闭工单做成右栏「更多操作」卡片常显，避免藏在下拉菜单里导致截图不可见。
- 详情页 SLA 进度条：09:12 创建至 09:42 当前，已用 30 分 / 共 4 小时（12.5%）。
- 趋势图标注了阈值 55 °C、超限区间和 09:12 工单创建时刻；图下附 13 个点的数值表，替代悬停提示，保证数据在截图中可见。
