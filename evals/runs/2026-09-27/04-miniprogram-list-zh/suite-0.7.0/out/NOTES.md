# NOTES：假设与决定（每条一行）

- 姿态：品牌化原生小程序（branded-native）；系统字体（PingFang SC），不加载 web 字体；375 px = 750 rpx，1 CSS px = 2 rpx。
- 状态栏、胶囊、原生标签栏、底部安全区都是按宿主位置画的占位；胶囊按 left 281 / top 50 / 87 × 32 画，自定义导航内容右边界约 232 px，留足避让。
- 自定义导航栏左侧放「当前位置」切换（苏州 · 工业园区 · 星湖街），不放页面标题：住户进来的第一问题是「附近谁能做」，位置决定一切结果。
- 品牌色选深青绿 #0E6B63（稳重、干净，区别于微信绿与促销红）；价格用赭红 #B8360F；所有文字对白底/浅底对比度 ≥ 4.8:1（WCAG AA），星标只作图标。
- 类目用可横向滚动的胶囊，右侧渐隐提示还有「管道疏通 / 收纳整理 / 搬家」；排序四项直接平铺成一排（一次点击即可切换，比下拉更适合年长用户），「筛选」在最右。
- 卡片整体可点进详情，不在卡片上另加「预约」按钮，减少重复噪音；「最近可约」为今天时用品牌色 + 「今天」标记，突出「什么时候能上门」。
- 「平台担保」「不通不收费」视为保障类标签，用浅青底 + 盾牌图标；其他标签中性灰。
- 筛选面板采用小程序常见的「从筛选栏下拉」形式，遮罩只盖列表区域：原生 tabBar 位于页面之上无法被页面遮罩覆盖，所以标签栏保持不变暗。
- 筛选面板底部在 0 结果时给出一句提示和最大的放宽项（3 km 内有 4 个），「查看 0 个结果」仍可点，进入空状态页（不做无理由禁用）。
- 「服务人员：不限」默认选中（它是单选项的默认值），未计入已选筛选数（3 个）。
- 空状态放宽建议的副文案（如「仍是今天上门、可开发票」）是根据 brief 数量的含义推断：每条只放宽一个条件，其余条件保持。
- 空状态建议的顺序按「对用户原意改动最小」排：先放宽距离（仍是今天），再改日期，最后去掉发票要求。
- 空状态上方的「已选」条件胶囊带 ×，可单独移除；页面底部提供「修改筛选」（重新打开面板）和「清除筛选」。
- 列表页第一屏完整显示 3 个服务，第 4 个在标签栏上方露出一部分，提示可继续滚动。
- 微信字体放大：布局以 flex 流式为主，卡片单行文字留有余量；本次只渲染了默认字号，大字号未单独出图（未验证）。
- 图片与图标全部为手绘内联 SVG（无第三方素材，无外部 URL）。
- 渲染：Playwright + 本机 Chrome，375 × 812，DPR 2，浅色模式；仅验证了 macOS Chrome 下的 PingFang 渲染，真机字体与换行可能略有差异。
