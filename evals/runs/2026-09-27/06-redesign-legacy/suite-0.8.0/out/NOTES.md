# Assumptions and notes (one line each)

- Mode: design-studio `redesign`, compressed to one screen for the 60-minute run; a single context plus one fresh-critic subagent, with no options board or directions round.
- For an arrived patient the primary button reads "Finish Check In · collect $25.00 copay" (fresh critique: plain "Check In" was ambiguous next to "Arrived"); it is the same Check In action and stays the most prominent control.
- Wait and room minutes are measured at 8:04 AM: Brennan 12, Chen 6, Natarajan 3 (waiting); Wright 9, Johansson 7 (in a room).
- "Late" = past start time and not arrived; at 8:04 no one qualifies (every 8:00 patient is here), so the section shows 0.
- "8 unconfirmed today" counts the [U] appointments between 8:00 and 1:30, the only part of the day in the data; the 3 for tomorrow come from the legacy alert.
- Per-clinician header counts come from the records: Rao 2 waiting, Kim 1 waiting, Feld 1 in a room, Ortega 1 in a room.
- Type legend and status legend moved behind "Key"; type stays as a colour stripe, and type names show on multi-slot cells and in the details panel.
- Legacy footer counts (96 / 3 arrived / 2 in room / 0 no-show) moved to the rail tiles and headings; 14 open is the legacy full-day figure.
- Location select kept as "Main ▾" in the top bar (it switches between Main and Eastside Annex); the user name stays visible and the role (Front Desk) moved into the account menu.
- The system maintenance notice (Sat 10/03) moved to Messages; server and build moved to Help › About; both are low-frequency and not tied to any task.
- Telehealth cells carry a video icon so the desk does not wait for someone to walk in; this data was already in the legacy type.
- Double booking at Feld 10:15 is taken from the legacy cell "REYES, LUCAS 3M fever / ADAMS, CHLOE 8F F/U", both [C], shown as two patients in one slot.
- Font: Atkinson Hyperlegible Next (Google Fonts, SIL OFL 1.1), chosen because it tells similar letters apart; system-ui is the fallback.
- The HTML is generated by src/build.mjs (not reviewed); out/schedule.html is static and opens from file:// with only the font loaded from a CDN.
- Floor: lint.mjs passes contrast, overflow and accessible names at 1280×800; stripes and status borders were darkened to ≥3:1 against their ground (color_tools.py).
