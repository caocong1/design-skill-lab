# 假设与决定（每条一行）

- 设计定位：每天使用的企业运维后台，保守结构（侧栏 + 顶栏 + 表格），个性只放在颜色纪律和数字字体上；强调色选深青 #0b6b7a（不用组件库默认蓝），状态色（红/琥珀/绿）只用于 SLA、优先级和状态语义。
- 字体用系统字体栈（PingFang SC / 微软雅黑），不从 CDN 加载中文字体；大号数字（SLA 剩余时间、读数、视图计数）用 DIN Alternate / Bahnschrift，取工业铭牌的语气，缺失时回退系统字体。
- 表格正文 13px（低于数据密集表格建议的中文 14px）：1440 宽下要同时放下 12 列且首屏 ≥ 10 行，这是有意的取舍；辅助文字不低于 12px。
- 「设备」列拆两行：编号在上、名称在下（小一号灰字），以节省列宽，内容与 brief 完全一致。
- 「已挂起（等备件）」拆为状态徽标「已挂起」+ 下方灰字「等备件」。
- SLA 列按语义分级：已超时＝红色 + 警示三角 + 加粗；剩余不足 1 小时（响应剩 35分）＝琥珀色 + 时钟；正常剩余＝正文色 + 时钟；计时暂停＝灰色 + 暂停图标；按时修复＝绿色 + 对勾；「超时 20分修复」（已关闭）＝灰色 + 警示三角，避免与进行中的超时混淆。颜色之外都有图标和文字。
- 优先级：P1 为实心红底白字，P2 琥珀浅底，P3 灰浅底，P4 仅描边——形状/填充强度本身也区分等级，不只靠颜色。
- 状态徽标每种都有独立图形（虚线圈、箭头圈、半实心圈、暂停、空心对勾、实心对勾）+ 文字。
