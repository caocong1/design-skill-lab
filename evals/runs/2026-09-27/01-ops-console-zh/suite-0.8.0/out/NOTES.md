# NOTES · 假设与决定（每条一行）

- 设计定位：冷静、高密度、常规的中文企业后台；首要信号是「超时 / P1」，其次是优先级和状态，其余信息退后。
- 字体用系统栈（-apple-system / SF → PingFang SC → 微软雅黑），不加载 Web 字体；数字用等宽数字（tabular-nums）。
- 表格正文 13px，工单号、时间、辅助信息 12px；全站最小字号 12px。
- 1440 宽放下 10 列：「设备」拆成两行（编号 / 类型）；「创建时间」「更新时间」两行显示（日期 / 时间）；标题和位置允许折行，只在空格和标点处断行。
- 超时行：首列左侧加红色竖条，SLA 文字改为红色加粗并带警示图标；超时状态靠竖条、图标和文字共同表达，不只靠颜色。
- SLA 分级是我定的：剩余不足 1 小时（响应剩 35分）用琥珀色加时钟图标；已超时用红色加三角图标；按时修复用绿色加对勾；超时后修复用红色常规字重加圆形感叹号；计时暂停用灰色加暂停图标。
- 状态徽章：每种状态有独立的图形（虚线圆 / 空心圆 / 半实心圆 / 暂停竖线 / 圆内对勾 / 实心对勾）并显示文字；优先级徽章显示「P1 紧急」等完整文字，P1 用实心红底。
- 「已挂起（等备件）」显示为「已挂起」徽章，后面跟灰字「等备件」。
- 快捷视图中「已超时 4」用红色计数和警示图标常驻提示；其他视图保持中性。
- 7 个筛选项全部放在一行，没有收进「更多筛选」：李敏每天要筛选几十次。
- 批量操作条替换表格工具栏左侧，并写明「已选 2 项（本页）」，另给出「选择全部 1,286 项」。
- 总页数 86 由「共 1,286 条，每页 15 条」算出。
- 行操作：所有行显示「查看」；待派单的行另有加粗的「派单」。工单号也能链接到详情。
- 列表页的「导出全部」「列设置」放在表格工具栏右侧，「新建工单」是页面主按钮。
- 空状态：筛选栏中已生效的三个条件高亮并可逐个移除；空状态正文复述这三个条件，并提供「去掉负责人条件」和「清除全部筛选」两个动作；「全部」视图的计数保持全局数字不变。
- 加载中：15 行骨架屏，形状与真实行一致；快捷视图计数也用骨架占位；工具栏显示「正在加载工单…」；「导出全部」禁用。
- 出错：快捷视图不显示计数（我假设计数和列表来自同一接口，也一起失败）；错误卡片写明 HTTP 502、请求编号、时间，给出「重试」（主按钮）和「复制请求编号」；筛选仍然可用。
- 出错文案里的「系统管理员」是通用的求助对象，不是 brief 里没有的具体人员或功能。
- 详情页：brief 中「更多」菜单下的「打印工单 / 复制链接 / 关闭工单」直接平铺在面包屑右侧，做成弱化的文字按钮，这样截图里看得到，也不需要点开菜单；「关闭工单」用红字区分。
- 详情页主按钮是「添加处理记录」（值班工程师最常用的操作），同时在处理记录区块顶部放一个次按钮入口；申请备件、转派、挂起、提交验收是次按钮。
- 详情 SLA 进度条上的「09:27 时限」和「现在 09:42」由 brief 数据推算：09:12 创建 + 15 分钟，当前时间 09:42。
- 趋势图结论句（「08:50 起超过 55 °C 阈值…」）和「09:12 自动创建工单」标注都直接取自 brief 数据；13 个点全部标注数值，不需要悬停也能读出。
- 处理记录按时间倒序（最新在上），适合主管快速看最新进展；09:35 的 3 张照片用带说明的占位缩略图表示（brief 里没有照片素材）。
- 「本月报警 3 次」用琥珀色强调；实时读数中超限的两项加红色顶边并标「超限」，正常项标「正常」。
- 只做了浅色主题和 1440 × 900 桌面视口（brief 只要求这个），没有做窄屏和深色主题。
- 源码在 `src/`（build.mjs 从同一模板生成 5 个页面，render.mjs 负责截图）；评审只看 `out/*.html`，这些 HTML 自包含，不依赖外部资源。
- 已关闭工单的 P1 徽章改为描边弱化样式，「超时 20分修复」改为中性文字加红色图标：红色实心只留给仍未完成的紧急或超时工单（第一轮评审 P1）。
- 列表有选中项时，「批量派单」是唯一的实心主按钮，「新建工单」降为次按钮。
- 详情页「关闭工单…」改为中性色，带省略号，表示点击后还有确认步骤（确认弹窗未绘制）。
- 输入框和复选框的边框对白色背景达到 3:1 以上（#8A94A3、#7F8998）；所有控件都有 2px 的 :focus-visible 描边，但没有截取焦点状态的图，这一项未验证。
- 流程：先做一轮渲染和 lint 检查（对比度、溢出、无名称控件全部通过），再请一位新的评审子代理打分（结论为需修改），修完 P1 和部分 P2 后重新渲染确认。没有做第二轮评审；字号层级（12/13/14/15 相邻）按原样保留。
