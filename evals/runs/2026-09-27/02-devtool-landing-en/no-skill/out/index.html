How it works

The network is no longer in the way.

An embedded SQL database with a SQLite-compatible dialect lives next to your UI. The server’s job shrinks to relaying changes between copies.

  1. 01

    Your app writes to its local database

    Plain SQL against a file on the device. Nothing waits on a round trip, and pending changes survive restarts while offline.

    INSERT INTO notes VALUES (…)
    local write · p50 0.8 ms
    notes.db
    on this device
    saved
  2. 02

    Driftless records it and merges per column

    Concurrent edits merge column by column using hybrid logical clocks. No conflict code to write.

    titledone
    Laptop"Q3 roadmap"0
    Phone"Q3 plan"1
    Merged"Q3 roadmap"1
  3. 03

    The sync server relays it to matching devices

    Every other device that holds matching rows receives the change. Shapes decide which rows each one holds.

    Sync servershape: WHERE team_id = ?
    Browserteam 7 ✓
    Androidteam 7 ✓
    Desktopteam 9 —

What’s in the box

A database, a sync engine and live queries.

One client library per platform, one open-source sync server. Run it yourself or let Driftless Cloud run it.

Reactive queries

db.watch re-runs a query whenever matching rows change, locally or from sync.

Partial sync with shapes

Each user syncs only the rows a filter selects, for example WHERE team_id = ?. Generally available in 1.4.

Custom merge functions

Columns merge automatically by default. Register your own merges for counters, lists and rich text.

Bring your own auth

Pass your own JWT. Row-level rules are checked by the sync server, not trusted to the client.

Works offline

The app keeps working with no connection. Pending changes survive restarts and sync when the network returns.

690 KB in the browser

Gzipped WebAssembly bundle, 30% smaller in 1.4. Storage is OPFS, so data persists between sessions.

FAQ

The questions you were going to ask.

Is it SQLite?
The storage engine is a fork of SQLite 3.46 with sync metadata; most SQLite SQL runs unchanged. Extensions that change the file format are not supported.
Do I need Driftless Cloud?
No. The sync server is a single open-source binary you can run anywhere, backed by Postgres or SQLite. Cloud is the managed version.
How big can a local database get?
In the browser, browser storage limits apply (usually a share of free disk). On native platforms the tested limit is 50 GB.
What happens when two people edit the same row offline?
Each column merges by hybrid logical clock. Register custom merge functions for counters, lists and rich text.
