> 中文导语：这是 Apple 自己公布的弹簧参数和判断阈值：SwiftUI `spring(duration:bounce:)` 默认 0.5 s、bounce 0，预设 `.smooth` / `.snappy` / `.bouncy` 基础回弹 0 / 0.15 / 0.3；`Animation.default` 自 iOS 17 起是 response 0.55、dampingFraction 1.0 的弹簧；WWDC23 给出 15% "还不算弹"、30% "明显弹"、超过约 0.4 "对 UI 元素太夸张"的感知刻度；WWDC18 的原则是"调弹性先从 100% 阻尼开始，只有手势带动量时才奖励一点过冲"。本仓库 motion 主题和 motion-tokens 此前只能写"少弹或不弹"而没有一手出处；现在有了。

## Key facts
1. `static func spring(duration: TimeInterval = 0.5, bounce: Double = 0.0, blendDuration: Double = 0)`. `duration` is "The perceptual duration… approximately equal to the settling duration, but for very bouncy springs, will be the duration of the period of oscillation"; `bounce`: "A value of 0 indicates no bounces (a critically damped spring), positive values… up to a maximum of 1.0 (corresponding to undamped oscillation), and negative values indicate overdamped springs with a minimum value of -1.0."
2. **Presets**: `smooth(duration: 0.5, extraBounce: 0.0)` with "base bounce of 0"; `snappy(duration: 0.5, extraBounce: 0.0)` with "base bounce of 0.15"; `bouncy(duration: 0.5, extraBounce: 0.0)` with "base bounce of 0.3". `Animation.smooth/.snappy/.bouncy` are available from iOS 13; the `Spring` presets from iOS 17.
3. **`Animation.default`** = `spring(response: 0.55, dampingFraction: 1.0, blendDuration: 0.0)`; "Prior to iOS 17, macOS 14, tvOS 17, and watchOS 10, the default animation is easeInOut." `withAnimation(_ animation: Animation? = .default, …)`.
4. Legacy forms: `spring(response: Double = 0.5, dampingFraction: Double = 0.825, blendDuration: TimeInterval = 0)`; `interactiveSpring(response: Double = 0.15, dampingFraction: Double = 0.86, blendDuration: TimeInterval = 0.25)` and `interactiveSpring(duration: TimeInterval = 0.15, extraBounce: Double = 0.0, blendDuration: TimeInterval = 0.25)`.
5. `interpolatingSpring(duration: 0.5, bounce: 0.0, initialVelocity: 0.0)` and `interpolatingSpring(mass: Double = 1.0, stiffness: Double, damping: Double, initialVelocity: Double = 0.0)`: "Preserves velocity across overlapping animations by adding the effects of each animation", whereas with `spring()` "each animation will be replaced by their successor, preserving velocity".
6. **`Spring` (iOS 17+) worked conversions in the docs**: `Spring(duration: 0.5, bounce: 0.3)` → `(mass, stiffness, damping)` = `(1.0, 157.9, 17.6)`; `Spring(mass: 1, stiffness: 100, damping: 10)` → `(duration, bounce)` = `(0.63, 0.5)`. Initialisers: `init(duration: TimeInterval = 0.5, bounce: Double = 0.0)`, `init(response:dampingRatio:)`, `init(mass: Double = 1.0, stiffness:damping:allowOverDamping: Bool = false)`, `init(settlingDuration:dampingRatio:epsilon: Double = 0.001)`. (Lab check, not stated by Apple: both examples match bounce = 1 − ζ and duration = 2π/√(k/m), e.g. ζ = 10/(2√100) = 0.5, 2π/√100 = 0.628.)
7. Curves: `easeInOut` has a "default duration of 0.35 seconds"; `timingCurve(_:_:_:_:duration: TimeInterval = 0.35)`.
8. UIKit (iOS 17+): `UIView.animate(springDuration duration: TimeInterval = 0.5, bounce: CGFloat = 0.0, initialSpringVelocity: CGFloat = 0.0, delay: TimeInterval = 0.0, …)`.
9. **WWDC23 10158 perceptual scale**: bounce "values have a range from -1.0 to 1.0"; "A bounce of 0 feels like a smooth, gradual change. A small bounce, like around 15%, doesn't feel very bouncy yet, but the long tail feels a little more brisk. And for larger bounce values like 30%, you do start to feel some noticeable bounciness. But you should be cautious about using values higher than around 0.4, since they may feel too exaggerated for a UI element."; "When you're not sure, use a spring with bounce 0, which is also what you get if you don't specify the bounce."; "springs are the only type of animation that maintains continuity both for static cases and cases with an initial velocity"; "you shouldn't wait for the settling duration for user-facing changes"; tuning order: "start by finding a duration value that gives a pacing that you like… then adjust the amount of bounce".
10. **WWDC18 803 principles**: "we recommend starting with 100% damping, or no overshoot when you're tuning elastic behaviors"; "if the gesture that's driving the motion itself has momentum, then you should reward that momentum with a little bit of overshoot"; Now Playing: tap → "100% damping", swipe to dismiss → "80% damping"; the two tunable properties are "damping ratio and frequency response"; instant response, "fully redirectable" and interruptible motion, lightweight touch amplified, rubber-banding at edges and hand-offs, "project momentum" (velocity plus deceleration rate pick the endpoint), 60 fps with motion stretching, detect multiple gestures "in parallel from the beginning".
11. **HIG Motion**: the only numbers are "30 to 60 fps" (games) and the visionOS caution against oscillation "around 0.2 Hz"; rules "Make motion optional", "avoid adding motion to UI interactions that occur frequently", "Let people cancel motion"; Liquid Glass motion is stronger under direct touch than under a trackpad.

## Not verified / open
- Apple publishes no spring values for system components (sheets, tab bars); these are API defaults and talk guidance, not component tokens.
- The WWDC transcripts were read as text; the talks' demos were not watched.
- HarmonyOS's `springMotion` defaults (0.55 / 0.825) equal SwiftUI's legacy `spring(response:dampingFraction:)` defaults (`harmonyos-motion-curves`); whether that is deliberate is not stated by either vendor.
