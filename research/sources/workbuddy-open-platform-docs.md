## Key facts
1. **Skill package layout**: `{skill-name}/SKILL.md` ("技能定义（必须）"), optional `references/`, `scripts/`, `templates/`.
2. **SKILL.md frontmatter table**: `name` (required), `display_name` (required; the Chinese marketplace name), `display_name_en` (required), `description` (required; purpose plus trigger words), `description_zh` (required), `description_en` (required), `allowed-tools` (optional, comma-separated), `version` (required; example `1.0.0`), `examples_zh` (optional), `examples_en` (optional), `author` (required; the partner name). Not in the doc: `category`, `tags`, any character, size or file-count limit, review rules.
3. **Expert package**: `.codebuddy-plugin/plugin.json`, `avatars/expert.png`, `agents/my-expert.md`, `README.md`. `plugin.json`: `name` (lowercase plus hyphens), `version` (semver), `description` (English), `author {name, email}`, `agents` string[], `expertType` `"agent"` | `"team"`, `agentName` (main agent file name without `.md`), `skills` string[] (optional), `homepage` / `license` / `keywords` (optional), `teamInfo` (required for a team), `displayName {en, zh}`, `profession {en, zh}`, `displayDescription {en, zh}` ("Chinese text must be 40–50 characters"), `avatar`, `categoryId` (01-ProductDesign, 02-Engineering, 03-GameSpatial, 04-DataAI, 05-MarketingGrowth, 06-ContentCreative, 07-SalesCommerce, 08-FinanceInvestment, 09-OperationsHR, 10-ProjectQuality, 11-SecurityCompliance, 12-IndustryConsultant, 13-TencentZone, 14-WorldWise, 15-Education), `defaultInitPrompt {en, zh}` (= the first quick prompt), `plugin` (= name), `tags` exactly 3, `quickPrompts` exactly 3, `dependencies {mcpServers, connectors}` (optional).
4. **Avatar**: 512 × 512 square, PNG recommended or JPG, "单张不超过 500KB", in `avatars/`.
5. **Agent markdown frontmatter**: `name` (= file name), `description` (English), `displayName {en, zh}`, `profession {en, zh}`, `maxTurns` (default 50), `skills` (preloaded); "Developers cannot add `tools`". No zip-size limit is stated.
6. **Expert team tree** (verbatim lines): `.codebuddy-plugin/plugin.json # ★ 配置文件（必须）`; `avatars/ # ★ 头像目录（必须）` (team.png, team-lead.png, member-*.png); `agents/ # ★ Agent 定义（必须）` with `{team}-team-lead.md # 主理人（名称须加专家团前缀，不可用通用 team-lead）`; `skills/` (optional, each with SKILL.md / references / scripts / templates); `.mcp.json` (optional); `bin/` (optional); **`settings.json # ★ 设置主理人（必须）`**; `README.md` (recommended). `expertType: "team"`, `teamInfo {leadAgent, memberAgents}`, `members[]` with `id`, `name {en, zh}`, `profession {en, zh}`, `avatar`, `role "lead" | "member"` (example ids `trading-team-lead`, `market-analyst`); template `trading-team.zip`; `displayDescription.zh` 40–50 characters. Not documented: `rules/`, `*_rules.md`, a member-count limit, example content of `settings.json`.
