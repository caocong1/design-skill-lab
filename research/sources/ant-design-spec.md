## Key facts
1. **Base and line height**: "从原先的 12 上升至 14" (50 cm reading distance, 0.3° visual angle); "主要字体为 14，与之对应的行高为 22"; "定义了 10 个不同尺寸的字体以及与之相对应的行高"; "字阶的选择尽量控制在 3-5 种之间".
2. **Formula** (`genFontSizes.ts`, `seed.ts`): `fontSize: 14`; `getLineHeight(fontSize) = (fontSize + 8) / fontSize` (14 → 1.5714…); sizes are `base · e^(i/5)` rounded down to even: 12, 14, 16, 20, 24, 30, 38, 46, 56, 68, i.e. line heights 20 / 22 / 24 / 28 / 32 / 38 / 46 / 54 / 64 / 76 (ratios 1.667 … 1.118).
3. **DESIGN.md scale** (size / line-height / weight): display-lg 38/46/600; headline 30/38, 24/32, 20/28; title 16/24 and 14/22 (600); body 16/24, 14/22, 12/20 (400); code 13/20; "only 400 and 600 in product UI". font-cn itself says regular 400 and medium 500 with "英文加粗 semibold 600": the two documents disagree on the second weight (500 vs 600); record both.
4. **Colours**: text light/dark 一级 `#000000E0` / `#FFFFFFD9`, 二级 `#000000A6` / `#FFFFFFA6`, 禁用 `#00000040` / `#FFFFFF40`; 一级边框 `#D9D9D9` / `#424242`; 分割线 `#0505050F` / `#FDFDFD1F`; 布局背景 `#F5F5F5` / `#000000`; font-cn claims text "保持在了 7:1 以上的 AAA 级对比度"; `tabular-nums` recommended. colors-cn: "形成了特有的 12 色", "基础色板共计 120 个颜色", "选择色板从浅至深的第六个颜色作为主色", brand `#1677ff`, neutrals "从白到黑的 13 个颜色". dark-cn: "基于 12 套基础色板，并结合透明度规则"; example inputs primary `#1890ff` on background `#141414`; "暗黑模式下避免使用对比很强的色彩".
5. **Seed and DESIGN.md tokens**: `sizeUnit: 4`, `sizeStep: 4`, `controlHeight: 32`, `borderRadius: 6`, `lineWidth: 1`, `motionUnit: 0.1`; easings e.g. `motionEaseInOut: cubic-bezier(0.645, 0.045, 0.355, 1)`, `motionEaseOutCirc: cubic-bezier(0.08, 0.82, 0.17, 1)`. DESIGN.md: spacing xs 4 / sm 8 / md 16 / lg 24 / xl 32; radius none 0, sm 2, md 4, DEFAULT 6, lg 8, xl 16, full 9999; durations fast 0.1 s / mid 0.2 s / slow 0.3 s, "Don't write custom cubic-bezier curves"; primary `#1677FF` hover `#4096FF` active `#0958D9`; success `#52C41A`, warning `#FAAD14`, error `#FF4D4F`; text `rgba(0,0,0,0.88/0.65/0.45/0.25)`; surfaces `#FFFFFF` / `#FAFAFA` / `#F5F5F5`; outline `#D9D9D9` / `#F0F0F0`; mask `rgba(0,0,0,0.45)`; popup shadow `0 6px 16px 0 rgba(0,0,0,0.08), 0 3px 6px -4px rgba(0,0,0,0.12), 0 9px 28px 8px rgba(0,0,0,0.05)`; front matter `version: alpha`, no date.
6. **Layout**: "网格的基数为 8"; "Ant Design 采用 24 栅格体系"; "统一的画板尺寸为 1440"; main resolutions "1920、1440 和 1366…1280"; gutters and breakpoints are not stated in the page text.
7. **6.x changes relevant to design** (changelog-cn): 6.0.0 "组件语义化结构" (per-slot `classNames` / `styles`), "杂项：默认使用 CSS 变量。", `useToken` exposes CSS variables, new `colorBorderDisabled`, `zeroRuntime`, mask blur on Drawer / Modal / Image, "Tabs 移除激活态文字阴影。", IE dropped; 6.3.0 "Grid 新增 `xxxl`（1920px）断点"; 6.3.1 / 6.5.1 `prefers-reduced-motion` honoured by Button, Checkbox, Radio, Switch, Segmented, Splitter, BorderBeam; 6.4.0 `colorErrorAffix` / `colorWarningAffix`, Badge `paddingInline`, BorderBeam, "Agent Readiness" files; 6.4.4 deeper `boxShadowTertiary`; **6.5.0 "新增 antd `DESIGN.md` 设计语言文件并发布到 ant.design/design.md"** (repo commits 2026-05-20 add, 2026-06-24 "improve DESIGN.md guidance for AI tools"); 6.6.0 ConfigProvider token `focusOutline`, Alert `borderRadius` token, Listy virtual list; 6.6.6–6.6.8 (October 2026) list no token or motion items.
8. Ant Design Mobile 5.43.0 (2026-09-14), nothing since; Ant Design X is digested in `ant-design-x`.
