Direction (reference/new-work.md)
7. Invention scale: extend a surface (no tournament, no DESIGN.md change) → whole surface in an established world (derive 5–7 structures, `concept-seed --scope surface` deals 3 as equal cards, lead kicker "THE ROLL") → create/replace a world (full direction round).
8. World round: name the product's unique mechanism, audience scene, cultural home; name "the page this category always ships and its predictable opposite" (both are the rut); a brief's literal metaphor gets at most one candidate; list **7** concrete systems/artifacts/rituals from the audience's world, ordered by resonance, spanning **≥3 material families** (more than 3 of 7 in one family = dig further).
9. **Direction dice** (`crates/context/src/concept_seed.rs`): key = random 8-hex (or `--from <key>`, or env `IMPECCABLE_CONCEPT_SEED`); `u = first 4 bytes (big-endian) of sha256("scope:salt:key") / (2^32−1)`, salt `index` (or `index:reroll-<n>`); assigned index = `3 + floor(u × (N−2))` with N = `--candidate-count` 5–7 (default 7), so the build is always candidate 3..N of the model's own resonance-ordered list, never its top two (only u = 1.0 exactly would overshoot to N+1). Surface scope deals the assigned index plus two more distinct indices drawn from 1..N, so the top two can appear there as non-lead cards. `NO_PRODUCT_MD` blocks the roll ("the dice stay in the cup until product truth exists").
10. Challengers come from a curated concept catalog: local only if `concept-ingredients.json` sits in the skill's scripts dir (the shipped skill does not include it), otherwise one GET to `https://impeccable.style/api/roll` (scope, mode, key, reroll counter; 4 s budget, `IMPECCABLE_API_TIMEOUT`). Unreachable → "degraded" roll: no challengers, bolder register unavailable, must be disclosed. Catalog validator (fixture schemaVersion 7): `qualityBar.principle`, `rejectIf` ≥5 gates, `reviewAxes` ≥8 axes. An anonymous choice ping follows each resolved round unless `DO_NOT_TRACK` or `IMPECCABLE_NO_TELEMETRY` is set.
11. Judging: fuse each challenger with product facts, compare with the assigned direction on exactly two axes (audience identification, product clarity) → verdict wins / competitive / declined; a declined challenger must still "raise" the assigned direction by one named discipline, written as a named line. At most 3 full-card challengers; one optional **IMPECCABLE'S PICK** card (never lead, never two); a permanent **canon exit** (category standard played straight, never recommended); re-roll registers plain / safer / bolder; after two consecutive re-rolls ask what quality is missing; "taste is never grounds" for a model-initiated re-roll; a user- or brief-pinned direction always beats the roll.
12. Decision UI: `serve-question --start --payload` serves a local page; `--wait --key` loops while exit 3, exit 4 = page closed (re-ask once via the structured tool, then proceed with the assigned direction), exit 2 at start = fall back to the structured question tool. Every card has the same anatomy: thesis, palette, materials, first viewport, honest risk.
13. Colour strategy picked before colours: Restrained (neutrals + one accent; default for Operate/Read), Committed (one saturated colour on **30–60%** of the surface), Full palette (3–4 named roles), Drenched. Dark vs light comes from one written sentence of physical scene, never by default.
14. Training-data default faces for Persuade/Experience (need a reason no other face satisfies): Fraunces, Playfair Display, Cormorant, Lora, Crimson, Newsreader, Syne, Space Grotesk, Space Mono, IBM Plex, Inter-as-display, DM Sans, DM Serif, Outfit, Plus Jakarta Sans, Instrument Sans. Operate/Read are well served by system stacks. Named calibration clusters: cream ground + high-contrast serif + terracotta/signal red; near-black + one neon accent + glowing edges; broadsheet hairlines + italic display serif + tracked mono labels. Stated rendition prior: warm/bookish/child-facing subjects come out cream + italic serif + lamplight; "treat that first palette as already spent".
15. **Direction contract** in the surface brief, ~150 words, six blocks: THESIS, OWN-WORLD, STORY, FIRST VIEWPORT, FORM (+ seed key), FINISH (fixed exit line). Never copied into shipped code, DOM, comments, bundles or metadata. On a new world DESIGN.md is written **after** the build by the documenter ("a rulebook written before the build gets defended against reality").

Build and verification
16. Build path `buildPath: comp|code` in `.impeccable/config.json` (local override in `config.local.json`); comp-led is default whenever image generation exists. Comp-led is a disk state machine (`build-phase start/advance/finish`): 3 comps → `comp-spec` regions (text/control/chrome vs plate/image/texture; no code region > ¼ of the comp) → `font-match` (measures cap height/weight from pixels, ranks Google Fonts by fingerprint distance) → plates (every raster region regenerated at **≥1.5×** its box, "a crop of the comp is a reference, never a shipping pixel") → hero gate: `comp-diff` **≥72%** with no hard veto (missing region, contradicted plate/text, SVG illustration, clipped plate, invented ink) → sections → motion → responsive (1280–1600 widths; `desktop.png` 1440 full page, `mobile.png` 390). Comp-led is called "a frontier-tier job"; smaller models should take code-led. Rationale: "Models systematically believe their HTML, CSS, and SVG recreation of an image succeeded when it did not."
17. Bounded verification (SKILL.md core principles; new-work §7): build fully, one batched inspection round (desktop + mobile, or shipped device classes on native), one fix batch, at most one confirm round; two rounds is the ceiling. Capture validity: settle entrance motion, full-page shots from the document top, open every file and confirm it shows what its name claims.
18. Every shipping raster carries provenance: `impeccable embed-prompt` writes the generation prompt or the sourced origin into the file; `embed-prompt --scan` must be clean before review.

Finish reviewer (skill/agents/impeccable-finish-reviewer.md)
19. Spawned fresh (`fork_turns: 0` on Codex), no browser, tools Read/Bash/Glob/Grep, `effort: high`, `max-turns: 30`; input packet: request, confirmed answers, artifact paths, screenshots, direction contract, hook findings, QUALITY BAR card, approved comp (or chosen decision comp labelled as critique reference), build state/spec/diff dirs, craft-floor path, platform refs on native.
20. Checks in order: 0 Evidence (missing/invalid capture → return only `recapture`), 1 Persistence, 2 Fidelity (element matrix match/adaptation/missing/contradicted/added; mandatory TYPE, MATERIAL, GROUND rows), 3 Ceiling, 4 Contract promise-by-promise (FORM must carry the seed key), 5 Truth (synthetic data labelled, no invented claims, plates shipped), 6 Floor (craft-floor Refuse list).
21. Exactly four dispositions: **ship / fix / rebuild / recapture**; output = disposition line + five sections (persistence, fidelity, ceiling, material_fixes ≤8, keep). Verdict pass scores each fix resolved / partial / unresolved plus ≤3 regressions; "Unresolved or partial material findings can never recompute to ship"; two rounds is the unattended budget. No-subagent harnesses use `degraded/finish-reviewer.md` and must disclose it.

Critique and audit
22. `critique` (reference/critique.md): Assessment A (design review) and B (detector + browser overlay) run as two isolated subagents; A must finish before detector output enters synthesis ("deterministic output still anchors judgment"); inline run must open with `⚠️ DEGRADED: single-context (<reason>)`. Nielsen 10 heuristics × 0–4 (= /40; `n/a` allowed on Persuade/Experience with renormalised max); bands 36–40 Excellent, 28–35 Good, 20–27 Acceptable, 12–19 Poor, 0–11 Critical (or 90/70/50/30 %); "Most real interfaces score 20–32 out of 40". Severity P0 Blocking / P1 Major / P2 Minor / P3 Polish. Working memory ≤4 items (5–7 borderline, 8+ overloaded). Five personas: Alex (power user), Jordan (first-timer), Sam (accessibility), Riley (stress tester), Casey (distracted mobile). `.impeccable/critique/ignore.md` is the only prior-run input; the targeted question is the last thing in the response.
23. `audit` (reference/audit.md): 5 dimensions scored 0–4: Accessibility, Performance, Theming, Responsive, Implementation Integrity.
24. Craft floor (reference/craft-floor.md): contrast body + placeholder ≥4.5:1, large ≥3:1; on coloured surfaces tint secondary text from that hue or the foreground, never gray; body measure 65–75ch; display max 6rem; tracking floor −0.04em; more space above a heading than below; states hover/disabled/loading/error/empty; theme the "browser surfaces" (selection, caret, scrollbars, focus rings, underline offset, tabular numerals). The Refuse list is framed as category defaults the brief's own words can earn back, not bans; it includes same-size icon+heading+text cards as page structure, nested cards, hero-metric template, section numbers without sequence, modal without need, gradient text, decorative glass, coloured border-left/right >1px, hard offset shadows outside neobrutalism, mono as costume, system display face, emoji/glyph icons, geometric masks for organic contours. The one exception is a kicker/eyebrow above a heading, stated as an absolute ban ("no brief earns it back"); the detector's `kicker-above-heading` rule says the same.

- skills/design-studio/references/process/directions.md: rut naming (category page + its opposite), 7 candidates across ≥3 material families, script-assigned lead that excludes the model's top two, a user-owned canon exit, re-roll registers, two-axis challenger judging with named "raise" lines, one "pick" card at most.
