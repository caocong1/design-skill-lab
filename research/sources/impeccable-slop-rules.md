## Key facts
1. **Framing** (page intro): "AI slop changes with the era and the model"; an era switch shows **2022 / 2025 / 2026** examples (2022: purple gradients, glass panels, neon glow; later eras: beige editorial layouts and a GPT-style neobrutalist take). 11 deliberately exaggerated example pages carry the detector overlay.
2. **Three kinds and three detection modes** (§ The catalog): kinds - *AI slop* (familiar AI habits), *Quality* (problems whoever made them), *Your design system* (choices outside the project's DESIGN.md). Modes - *Source* (detector on files, no browser), *Browser* (rendered page via Chrome extension or a URL), *Design review* (needs judgement; `critique`). "61 detector rules and 6 patterns for design review"; "a finding is a reason to look closer".
3. **Counts** (English, 67): Your design system 4 · Visual details 8 · Typography 11 · Color & contrast 7 · Layout & space 12 · Motion 6 · Copy 5 · Imagery 4 · General quality 10.
4. **Your design system (Source)**: font outside DESIGN.md; colour outside DESIGN.md; radius outside DESIGN.md; font size outside DESIGN.md.
5. **Visual details**: decorative grid-line background; thick border accent on a rounded element; glassmorphism everywhere (review); side-tab accent stripe; hairline border plus wide soft shadow ("choose the edge or the shadow"); repeating-gradient stripes; extreme radius on cards (review; example 44 px on a small card); rough hand-coded SVG illustrations (review).
6. **Typography**: label (eyebrow) above a heading; tiny interface text (quality); flat type hierarchy; icon tile stacked above a heading; italic serif display headline; pill badge above the hero headline; oversized hero headline (a long sentence at display size); crushed letter-spacing; overused font - names **Inter and Geist** ("keep established brand fonts when they fit"); single font for everything (review; "vary size, weight, spacing before adding a family"); all-caps body text (quality).
7. **Color & contrast**: radial-gradient halo on dark; soft spotlight behind content; "AI colour palette" (purple gradients, bright cyan on dark); dark mode with glowing accents; gradient text; grey text on a coloured background (quality - use a darker tint or light text and check contrast); cream/beige palette as the reflex default.
8. **Layout & space**: tiny numbered section labels (01 Discover 02 Design…) without a real sequence; cards flush against a scroller edge (browser); text covered by another element (browser); unbalanced opening columns (browser); heading closer to the previous section than to its own content (browser); hero metric layout (review); identical card grids (review); monotonous spacing; nested cards; line length too long - **65-75 characters** (browser); content overflowing its container (browser); clipped menus/popovers inside overflow containers (browser).
9. **Motion**: pulsing status dot; decorative blinking cursor (browser); auto-scrolling marquee; bounce or elastic easing on routine UI ("let it settle quickly"); animation that changes layout (quality - animate transforms); images that zoom/rotate on hover.
10. **Copy**: the same text repeated inside one container (quality); em-dash overuse; generic marketing claims ("supercharge", "world-class", "enterprise-grade", "next-generation"); forced contrast ("Not a feature. A platform."); calling things "theater".
11. **Imagery**: placeholder-style illustrations (generic circles and blocks); jagged image masks (quality); images hidden under near-opaque overlays (quality; example "94 % wash"); broken or placeholder image `src` (quality).
12. **General quality**: JavaScript errors on load (browser); content stuck invisible because its entrance animation never ran - "make it visible by default" (browser); cramped padding (browser; example 2 px vertical); body text touching the viewport edge (browser); justified text without hyphenation; low-contrast text - **WCAG AA 4.5:1 regular / 3:1 large**; skipped heading level; tight line height - start around **1.5×**; tiny body text - start around **16 px**; wide letter-spacing on body text.
13. **Run it** (§ Run it yourself): `npx impeccable detect src/` or `npx impeccable detect http://localhost:3000` (local or CI, no AI conversation); `critique` combines judgement with the checks; Chrome extension "Scan page" with overlays.
14. **Chinese mirror is stale** (impeccable.cn/slop, same day): still 46 rules in 8 groups (visual 7, typography 10, colour 5, layout 8, motion 3, copy 4, imagery 1, general 8), era switch only 2022 / 2026, modes CLI / browser / LLM-only / optional (`--gpt`, `--gemini` provider-specific rules, off by default). Its intro states "41 deterministic + 4 optional + 5 LLM-only", which does not add up to its own 46. It still names Inter, Geist, Space Grotesk and "the newest reflex", Instrument Serif; the English page now names only Inter and Geist.
15. **What the English update added vs the 46-rule list**: the 4 design-system drift rules; browser layout rules (text covered, unbalanced columns, heading proximity, cards flush to scroller, JS errors, content stuck waiting to appear); motion rules (pulsing dot, blinking cursor, marquee); copy rule (repeated text in one container); imagery rules (placeholder illustrations, jagged masks, hidden-under-overlay); decorative grid-line background; halo and spotlight backgrounds; tiny interface text. Specific numbers the Chinese page gave (padding ≥ 8 px ideally 12-16 px, body ≥ 14 px ideally 16 px, line height 1.5-1.7, tracking ≤ 0.05em, card radius 12-16 px with pills only for tags and buttons, adjacent type steps ≥ 1.25×) are softened on the English page to "start around" values or dropped.
