## Key facts
Versions and packaging
1. 130,871 stars (the most-starred of the design-specific skill repos in this lab's 2026-09-27 survey; the general anthropics/skills collection has more), created 2025-11-30, MIT. Latest GitHub release **v2.15.0** (2026-08-13); npm `ui-ux-pro-max-cli` **2.15.0** (same day; installs the `uipro` command). At this commit `.claude-plugin/*.json` and `skill.json` still say 2.13.0 and `cli/package.json` says 2.5.0: version strings are out of sync. README warns the old `uipro-cli` package (2.2.3) is stale. `ui-ux-pro-max/SKILL.md` last changed 2026-08-13.
2. Install: Claude Code `/plugin install ui-ux-pro-max@ui-ux-pro-max-skill`, or `npm i -g ui-ux-pro-max-cli` then `uipro init --ai <platform> [--global]` (19 platforms listed in `skill.json`). The search scripts need Python 3 stdlib only and "make no network calls" (README §Prerequisites); the claudekit `design` skill's logo/icon generators do call external image APIs (Gemini, Atlas Cloud, MuAPI) with the user's keys.
3. **7 skills** in `.claude/skills/`: `ui-ux-pro-max` (214 lines, the core), plus 6 with `author: claudekit`: `design` (logo generation "55 styles" via Gemini / Atlas Cloud / MuAPI, a 50-deliverable corporate identity program, icons, social images), `banner-design`, `brand`, `design-system` (three-layer tokens primitive → semantic → component, slides), `slides` (Chart.js HTML decks), `ui-styling` (shadcn/ui + Tailwind + canvas posters). Its `canvas-fonts/` (81 files: 54 .ttf + 27 OFL texts) is byte-identical to `skills/canvas-design/canvas-fonts/` in anthropics/skills (compared at anthropics/skills@3337550, same sha1 for every file), and its Apache-2.0 LICENSE.txt matches Anthropic's except that the copyright line is left as the template placeholder.

Data tables (`.claude/skills/ui-ux-pro-max/data/`, counts from `catalog-summary.json`, verifiedAt 2026-08-26, and row counts I took)
4. `styles.csv` 88 rows × 29 columns: **79 searchable** = 50 `active` + 29 `supplemental`; 9 `deprecated` rows carry `Replacement Domain`/`Replacement ID` redirects (e.g. "Bento Grids (Legacy)" → `style:bento-box-grid`; 8 old landing-page "styles" → `landing:*` patterns). Types: General 48, Mobile 17, BI/Analytics 10, Landing Page 8, Platform/System 4 (Fluent 2, Shopify Polaris, Adobe Spectrum, Spectrum 2), Platform/Material 1 (Liquid Glass, "Apple platforms, 2025"). Each row has light/dark support, performance cost, accessibility risk + requirements, era/origin, AI prompt keywords, CSS keywords, an implementation checklist and design-system variables.
5. `products.csv`, `colors.csv`, `ui-reasoning.csv`: **192 rows each, aligned 1:1 by product type**. A palette row has 16 semantic roles (Primary/On Primary, Secondary, Accent, Background, Foreground, Card, Muted, Border, Destructive, Ring…). A reasoning row has recommended pattern, style priority, colour mood, typography mood, key effects, JSON decision rules, anti-patterns, severity, confidence.
6. `typography.csv` 74 font pairings (heading, body, mood, Google Fonts URL, CSS import, Tailwind config); `google-fonts.csv` 1,934 families (category, axes, subsets, popularity/trending rank) with a sha256-pinned licence snapshot and a promotion policy (unlicensed families excluded, changes need explicit approval).
7. Other tables: `ux-guidelines.csv` 119, `landing.csv` 34 patterns, `charts.csv` 25 (incl. data-volume threshold, accessibility grade, fallback, library), `icons.csv` 105 curated (Phosphor upstream 1,512), `motion.csv` 17 GSAP presets (tiered Subtle/Standard/Complex, with duration/easing/snippet), `app-interface.csv` 32, `react-performance.csv` 44, and `stacks/*.csv` for **22 stacks** = 1,271 guideline rows (1,093 with a Docs URL; `Verified At` 2026-08/09; 71 marked deprecated).
8. `data-provenance.json`: 51 records only (31 reasoning profiles of 192, 6 styles of 88, 12 dataset contracts, 2 snapshots); 62 sources are `derived` (other CSVs in the same repo) and 52 `official` (e.g. Apple Liquid Glass docs, m3.material.io, fluent2.microsoft.design, WCAG 2.2 Understanding pages). Freshness policy: manual-verified 365 days, needs-review 90 days. Reasoning `confidence` values (e.g. 0.88, 0.92) are self-assigned, and only 31 of the 192 `ui-reasoning.csv` rows carry one (the same 31 that have provenance records).

Search script and generator
9. `scripts/search.py "<query>" [--domain d | --stack s | --design-system] [-n N] [-p "Project"] [--persist --output-dir <root> [--page <name>] [--force]] [--variance|--motion|--density 1-10] [-f ascii|markdown | --json]`. Domains: product, style, color, typography, google-fonts, chart, ux, landing, icons, gsap, react, web; auto-detected when omitted (SKILL.md admits it can misroute overlapping terms such as "font", which matches both `typography` and `google-fonts`). `-n` is `--max-results` (1–20, default 3).
10. Ranking is BM25 (`core.py`, k1 = 1.5, b = 0.75) over lower-cased, punctuation-stripped, whitespace-split tokens of ≥2 characters (stopwords removed), with alias normalisation; no stemming and no CJK segmentation ("后台管理 控制台" tokenises to two whole runs).
11. `--design-system` runs five domain searches in one loop (product 1, style 3, color 5, landing 2, typography 2 results; the README calls them "parallel", the code is sequential), applies the matching `ui-reasoning.csv` rule, and prints pattern, style, 16-role palette as CSS variables, heading/body fonts with import URL, key effects, anti-patterns and a pre-delivery checklist (no emoji icons, `cursor-pointer`, 150–300 ms hover transitions, 4.5:1 text contrast, visible focus, reduced motion, 375/768/1024/1440 px). A dark palette is derived automatically when the query or style is dark (background #0F172A, ring chosen for ≥3:1).
12. Persistence: `design-system/<slug>/MASTER.md` ("global source of truth") + `pages/<page>.md` overrides; an existing MASTER.md is never overwritten without `--force`, and `--force` needs explicit user authorisation. Page files override Master when present.
13. Query contract (SKILL.md): one dominant intent, **2–5 terms**, one constraint; verify the result's domain and identity; retry once with a narrower query; otherwise say no verified match was found; "Do not persist unverified output"; never present a 0-result search as data.
14. Optional dials (added by PR #402, merged 2026-07-02): `--variance` (biases style category), `--motion` (attaches a GSAP snippet by tier), `--density` (spacing scale 24–96 / 16–64 / 8–32 px).
15. Rule priority table (SKILL.md): 1 Accessibility, 2 Touch & Interaction, 3 Performance, 4 Style Selection, 5 Layout & Responsive, 6 Typography & Color, 7 Animation, 8 Forms & Feedback, 9 Navigation, 10 Charts & Data. Numeric rules in `references/quick-reference.md` include targets 44×44 pt / 48×48 dp, 8 px between targets, 16 px minimum mobile body text, 4pt/8dp spacing scale, 30–50 ms stagger per item, feedback within 100 ms, sidebar at ≥1024 px; attributed to "Apple HIG, MD" without links. `pro-rules.md` is a native-app pre-delivery checklist (e.g. tap feedback within 80–150 ms, meaningful icons ≥3:1).

## What it changes for the skills
- skills/design-studio/references/catalog/ (generated by scripts/build-catalog.py; catalog stream): UUPM's style lifecycle (active / supplemental / deprecated with replacement ids) supports our `status` field and suggests an optional `replaced_by` for sunset rows.
- skills/design-studio/scripts/catalog.py: keep the query discipline (one intent, 2–5 terms, retry once, report "no verified match", never persist unverified output) and add CJK bigram matching, which UUPM lacks.
- skills/design-studio/references/process/system.md: the MASTER + page-override split maps onto our DESIGN.md + `surfaces/<surface>.md`; adopt "never overwrite the system of record without explicit authorisation".
- skills/design-studio/references/fundamentals/color.md: a palette that passes 4.5:1 can still be the category mean (facts 16–18); contrast is the floor, identity comes from the direction, not from an industry lookup table.
- skills/design-studio/references/fundamentals/anti-slop.md: "industry → style/palette/font" tables produce the category default by construction; cite facts 17–20 as evidence.
- skills/design-studio/references/process/research.md: provenance with a freshness policy (365 d verified / 90 d needs-review) mirrors our review_by; note that "derived" sources are not evidence.
- skills/design-studio/references/disciplines/data-dense-ui.md: `charts.csv` columns (data-volume threshold, accessibility grade, fallback) are a useful checklist shape for chart choice.
- skills/implement-design/references/stacks.md: per-stack guideline rows with Docs URL + Verified At show the maintenance format for stack rules.
