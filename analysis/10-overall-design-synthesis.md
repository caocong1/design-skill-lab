# 跨来源总综合：一个会做设计的 agent 需要什么

> 分析版本：1.0 ｜ 最后更新：2026-09-21 ｜ 覆盖来源：`analysis/01` 至 `analysis/09` 涉及的全部来源与资源目录 ｜ 版本见 `analysis/SOURCE_INDEX.md`

这是快速阅读路径的第一站。它把九篇专题分析收敛成几条判断，并说明这些判断怎样落进 skill 套件。

## 综合结论

1. **设计 agent 的失败模式是"回归均值"，不是"不会设计"。** 六个同类项目的开场白一致，Anthropic 的 skill 在半年内更换了整份"生成感特征清单"这件事更说明：回避清单追不上模型自己的输出分布。耐久的判据只有一个——**这个选择是否无论主题是什么都会出现**。（`analysis/02`）
2. **媒介是代码，眼睛是截图。** 几乎所有来源都隐含同一个前提：设计要被看见才算数。对 agent 来说这意味着"渲染 → 看 → 改"是核心循环，与工程里的"跑测试"等价，也要遵守同一条诚实规则：没验证的要说没验证。本仓库的截图脚本第一次运行就抓到一个真实问题——无头 Chrome 继承操作系统的深色模式，导致"浅色截图"其实是深色的——这正是"不看就是猜"的例证。（`analysis/02`、`analysis/04`）
3. **参考先于创造，但产出必须是动作而不是链接。** 选源看粒度、真实度、易腐度；每次至少混用两类来源；被反爬拦住就换源或把链接交给用户。（`analysis/01`）
4. **先发散再收敛，而且发散必须发生在真实的轴上。** 换个强调色不算方案。方向要在字体气质、色彩策略、版式语法、密度、形状、层次手法、图像策略、动效个性上拉开，并用一个名字和一句概念固定下来，供后续每个决定对照。
5. **系统先于页面。** 哪怕只做一页，也隐含字号阶梯、间距阶梯、色彩角色、圆角逻辑、层次与动效 token。色阶的每一级是一份角色契约，模式（暗色、品牌、密度）只是重新映射。（`analysis/05`、`analysis/07`）
6. **能算的不要估，能机械检查的不要靠自觉。** 对比度、色阶、验链、目录视图是否过期、分析文件格式——都交给脚本。这条来自姊妹项目，也被 Impeccable 的"61 条无 LLM 检测规则"与 DESIGN.md 的 lint/diff 印证。（`analysis/02`、`analysis/07`）
7. **不愉快路径才是设计。** 空、加载、错误、部分失败、超长与混排文本、禁用、焦点、离线、首次使用、各窗口级别、暗色、减少动态效果。Vercel 清单、微信指南、GOV.UK 体系在这一点上完全一致。（`analysis/03`、`analysis/08`）
8. **"合适"高于"出彩"。** 每天用的工具型产品、政务与受监管领域、既有品牌与系统内部、平台原生应用——这些场景里约定俗成就是好品位；此时的"套路"指的是粗心（间距不一、状态没设计、没人选过的默认主题），不是惯例本身。
9. **中文语境有一整套不能照搬的规则**：标点禁则与挤压、中西文间距约定、无斜体、字体授权的法律风险、小程序胶囊、红涨绿跌、国内大屏的默认审美。（`analysis/08`）
10. **授权是设计的一部分。** 字体、图标、插画、图片、着色器各有许可；Remix Icon 在 2026-01 改了许可证、Shadertoy 默认是禁止商用的 CC BY-NC-SA——这类事实只有逐条核对才会知道。（`analysis/01`）

## 形态选择：一次设计任务要动用多少流程

`小修小改（直接做 + 截图）` < `单个页面 / 组件（design read → 参考 → 设计 → 自评）` < `多方案（brief → 方向 → 方案板 → 收敛）` < `完整设计（再加系统、关键屏、动效、素材、评审、交付）`。

流程的量应被需求拉动：给一个已有设计系统的后台加一个筛选栏，不需要方案板；从零做品牌，跳过策略页就是在盲画。

## 后续可分析方向

- **平台规范的一手摘要**：Apple HIG（含 Liquid Glass 与分层图标）、Material 3 Expressive、HarmonyOS 设计指南——本轮因站点为 JS 应用或网络不可达而缺失，是当前最大的证据缺口。
- NN/g 十条启发式与响应时间三阈值；Baymard 的表单与结账研究；GOV.UK 表单模式。
- Refactoring UI 公开文章；Rauno Freiberg《Invisible Details of Interaction Design》与 interfaces.rauno.me。
- Evil Martians OKLCH 文章、Stripe《Designing accessible color systems》、Linear 的主题生成——色彩系统三件套。
- Ant Design 设计价值观与 AntV 可视化设计原则；数据大屏的系统性研究（目前只有经验性总结）。
- 品牌方向：Chermayeff & Geismar & Haviv 的标志评判标准、若干份真实品牌规范的目录结构对比。
- 平面方向：Müller-Brockmann 栅格、Thinking with Type 的 Grid 章节、演示文稿的叙事结构（Duarte / Sequoia）。
- Impeccable 的 61 条确定性检测规则逐条研读，为 `SEED-002` 的设计 lint 脚本做准备。
- Google PAIR Guidebook、Microsoft HAX Toolkit。
