## What happened

A request for six interface directions in a new host project returned the lab's completed showcase
styles as though they were new designs. The options procedure did not explicitly forbid using the
lab's demos and old boards as a candidate pool.

## Expected / suggestion

Derive every option from the current host brief, with traceable referents and seed provenance. Lab and
showcase directions may contribute an isolated, justified move but never a reused or lightly renamed
name-thesis-axes-layout bundle. Add a focused regression where the whole lab is visible to the agent.
